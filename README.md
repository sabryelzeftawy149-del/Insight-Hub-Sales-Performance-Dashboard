# 📊 Insight Hub – Sales Performance Dashboard 360°

A comprehensive Power BI dashboard delivering a 360° view of sales, customer, and product performance — built with custom HTML visuals, Base64 encoded images, interactive tooltips, and dynamic bookmark navigation for an app-like user experience.

## 📌 Project Overview

**Insight Hub** is an executive analytics dashboard designed to help stakeholders monitor sales performance, customer behavior, and product trends in a single, unified experience. The report is structured across 4 pages:

* **Dashboard Home Page** – Central navigation hub with quick access to all report sections.
* **Executive Overview** – High-level KPIs and monthly trends.
* **Sales & Customer Analysis** – Revenue, orders, and top customer insights.
* **Product Performance Analysis** – Category-level sales performance and product trends.

---

## 🎯 Key Features & UX Highlights

### 📈 KPIs Tracked
* Revenue (with Previous Month comparison)
* Orders
* Average Order Value (AOV)
* Sold Products
* Month-over-Month (MoM) % change indicators (color-coded: green = growth, red = decline)

### 🗺️ Visuals & Analysis
* **Product Category Performance** – Donut chart + category-level revenue breakdown
* **Monthly Product Views vs Sales** – Trend comparison of seen vs. sold products
* **Customer Distribution by Location** – Bubble chart across regions
* **Monthly Revenue & Orders Trend** – Dual-line trend analysis
* **Sales Performance by Country** – Geographic map visualization
* **Top 10 / Bottom 10 Customers by Revenue** – Ranked bar charts
* **Monthly Category Sales Trend** – Multi-category trend lines
* **Category Performance Summary** – Detailed table with revenue, previous revenue, and growth %

### 🎨 UI/UX & Aesthetics
* **Custom HTML Visuals & Dynamic SVG Image URLs** – Rendered directly from the data model for country flags, icons, and dynamic visual elements.
* **Dark-themed UI** – Consistent, modern, and polished design across all pages.
* **Sidebar Navigation** – Intuitive icon-based navigation for seamless switching between report pages.

---

## ⚙️ Advanced Power BI Techniques

✅ **Interactive Tooltips** on all visuals for contextual, on-hover insights.  
✅ **Report Page Tooltip** on the map chart — displays each country's flag and detailed sales data on hover.  
✅ **Bookmark Navigation** to toggle seamlessly between Top 10 and Bottom 10 Customers by Revenue, with buttons that dynamically switch visibility based on the selected view.  
✅ **Custom HTML & Dynamic SVG Image URLs** for robust offline image handling without reliance on external image URLs.  

---

## 🛠️ Tools & Technologies

* **Power BI Desktop** – Report design and interactive dashboard creation.
* **Power Query (M)** – Data cleaning, transformation, and Base64 image preparation.
* **Data Modeling** – Star Schema design for optimized performance.
* **DAX** – Advanced calculations, MoM % changes, Time Intelligence, and dynamic measures.
* **HTML / SVG Image URLs** – Custom visual elements, flags, and icon rendering.
* **Geographic Mapping** – Map visualizations for spatial sales analysis.
